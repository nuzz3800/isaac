# '이 색 누구게?' (단순화 캐릭터 맞추기) 사진 넣는 곳

여기에 이미지 파일을 **짝으로** 넣으면 게임에 자동 반영돼요.

- **문제 그림**: `루피.png` — 캐릭터를 단순화한 그림 (색 팔레트 등)
- **정답 사진**: `루피2.png` — 같은 이름 뒤에 `2`를 붙인 실제 캐릭터 사진
- 파일명(2 제외)이 곧 정답 이름으로 화면에 표시돼요
- 지원 형식: jpg, jpeg, png, webp, gif
- 짝이 안 맞는 파일은 게임 시작 화면에서 알려줘요
- 넣은 뒤에는 빌드+배포가 필요해요 (Claude에게 "사진 넣었어"라고 하면 처리)
