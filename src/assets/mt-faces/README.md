# 인물 맞추기 사진 넣는 곳

여기에 이미지 파일을 넣으면 MT 인물 맞추기 게임에 자동으로 반영돼요.

- **폴더명이 곧 카테고리**: `국내/`, `해외/`, `캐릭터/` — 게임이 각 판에 카테고리를 골고루 분배해요. 폴더는 자유롭게 추가 가능
- **파일명이 곧 정답 이름**: `아이유.jpg`, `손흥민.png`, `유재석.webp` ...
- 지원 형식: jpg, jpeg, png, webp, gif
- 팀당 15장 × 2판이라 **총 60장 이상** 필요 (부족하면 판 수 자동 축소)
- 넣거나 옮긴 뒤에는 빌드+배포가 필요해요 (Claude에게 "사진 넣었어"라고 하면 처리)
